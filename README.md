# Social Robot Speech and Gaze Pipeline

This repository combines the thesis prototypes for:

- speech-to-speech interaction with ReSpeaker, Whisper, Piper, Gemini, and local Qwen/Ollama;
- ROS 2 audio and transcription components;
- L2CS-Net gaze estimation and webcam engagement experiments.

## Layout

- `speech_to_speech/`: speech interaction and ROS 2 prototypes.
- `gaze/L2CS-Net/`: L2CS gaze-estimation code and demo.

Model weights, virtual environments, recordings, build outputs, and API credentials are intentionally excluded. Download models separately and provide API keys through environment variables.
