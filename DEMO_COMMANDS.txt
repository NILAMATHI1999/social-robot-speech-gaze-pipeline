DEMO COMMANDS - run each block (laptop)            updated 24 Nov 2026
=====================================================================
Copy one block at a time into the terminal.
For the voice-guided tests: laptop speaker (no headphones), phone light on your face (phone not in the picture).
For 1, 2 and 10: set your OpenAI key in this terminal first (never in a file).


# 1. WHOLE ROBOT, MULTI-PERSON (new): tracker IDs + gaze + lips per person + partner lock + Whisper + LLM + voice
#    tiny detects the language (other languages ignored), base.en writes English, Smart Turn ends sentences
cd ~/projects/social-robot-speech-gaze-pipeline/mvp
GAZE_SCRIPT=../vision/people_gaze.py USE_SMART_TURN=1 ~/mvp_venv/bin/python chat_demo.py --model base.en --lang-model tiny --gaze


# 2. WHOLE ROBOT, ONE PERSON (the version that worked before): biggest face + lips + Whisper + LLM + voice

USE_SMART_TURN=1 ~/mvp_venv/bin/python chat_demo.py --model base.en --lang-model tiny --gaze


# 3. MULTI-PERSON VISION ONLY: each person gets an ID box; green = LOOK, orange = AWAY; white box = partner
#    live webcam; q = quit
cd ~/projects/social-robot-speech-gaze-pipeline/vision
~/step1_vision_venv/bin/python people_gaze.py


# 4. MULTI-PERSON VISION ON A LAB VIDEO (2 people): shows IDs + who looks at the camera

# 5. TRACKER, LIVE SWITCHING: keys 1-6 change the tracker (6 = TrackTrack), r = record clip, q = quit
